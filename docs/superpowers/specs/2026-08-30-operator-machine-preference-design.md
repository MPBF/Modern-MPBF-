# تثبيت آخر ماكينة لمستخدم الإنتاج

## الهدف

تمكين مستخدم لوحات الفيلم والطباعة والتقطيع من متابعة إدخال الإنتاج باستخدام آخر
ماكينة اختارها، دون إعادة اختيارها لكل عملية، مع إمكانية تغيير الماكينة يدوياً
في أي وقت.

## النطاق

يشمل السلوك لوحات:

- إنتاج الفيلم، حيث يوجد اختيار ماكينة داخل نافذة إنشاء الرول.
- إنتاج الطباعة.
- إنتاج التقطيع.

لا يشمل هذا التغيير حفظ الاختيار في الخادم أو قاعدة البيانات، ولا يغيّر مسارات
حفظ الإنتاج الحالية أو الصلاحيات أو قواعد تصفية الماكينات.

## التصميم المعتمد

### التخزين

يُحفظ معرّف الماكينة في `localStorage` بمفتاح مركب من:

1. نوع المرحلة: `film` أو `printing` أو `cutting`.
2. معرّف المستخدم المسجّل دخوله.

بهذا تكون اختيارات المستخدمين والمراحل مستقلة على نفس الجهاز. إذا تعذر الوصول
إلى `localStorage` تستمر اللوحة بالعمل كاختيار مؤقت للجلسة.

### السلوك عند فتح اللوحة

- تُقرأ قيمة الماكينة المحفوظة للمستخدم والمرحلة.
- لا تُستخدم القيمة إلا إذا كانت ضمن قائمة الماكينات النشطة والمطابقة للقسم.
- إذا كانت القيمة غير موجودة أو أصبحت غير صالحة، يُفرّغ الاختيار ويظهر طلب
  اختيار ماكينة جديدة.
- عند اختيار ماكينة، تُحدّث الحالة فوراً وتُحفظ القيمة.

### تعديل الاختيار

يظل اختيار الماكينة مرئياً في بطاقة الماكينة الحالية. زر واضح باسم «تعديل
الماكينة» يتيح فتح القائمة وتغيير الاختيار. لا يوجد قفل يمنع التعديل؛ التثبيت
يعني الافتراضي فقط.

### تدفق كل مرحلة

- الفيلم: تمرير المعرّف المثبت إلى نموذج إنشاء الرول، مع إبقاء الاختيار داخل
  النموذج قابلاً للتغيير، وحفظ أي اختيار جديد.
- الطباعة: استخدام المعرّف المثبت عند نقل الرول إلى الطباعة.
- التقطيع: استخدام المعرّف المثبت عند إكمال التقطيع.

## الواجهات والبيانات

لا توجد تغييرات API أو مخطط قاعدة بيانات. تستمر الطلبات في إرسال:

- `film_machine_id`
- `printing_machine_id`
- `cutting_machine_id`

كما هي حالياً. التعديل محصور في إدارة الاختيار الافتراضي في الواجهة.

## الحالات الخاصة والأخطاء

- أول استخدام أو بعد مسح بيانات الموقع: يظهر الاختيار فارغاً ويُطلب تحديد
  الماكينة قبل الحفظ.
- ماكينة غير نشطة أو تغيّر قسمها: تُرفض كقيمة محفوظة ويُطلب بديل.
- فشل التخزين المحلي: لا يظهر خطأ يعطل الإنتاج؛ يبقى الاختيار صالحاً حتى
  إعادة تحميل الصفحة.
- تبقى أسماء الماكينات معروضة عبر دالة الترجمة الحالية، ولا تُستخدم الألوان
  وحدها للدلالة على الحالة.

## الاختبار والتحقق

- اختبار عزل المفاتيح بين مستخدمين مختلفين ومراحل مختلفة.
- اختبار إسقاط قيمة محفوظة غير موجودة ضمن الماكينات النشطة.
- اختبار أن الإرسال يستخدم القيمة المثبتة دون إعادة اختيار.
- فحص TypeScript والبناء الإنتاجي وفحص حجم الملفات.
- التحقق من اللوحات الثلاث بعد إعادة تشغيل التطبيق.
