# فلترة الحضور اليومي حسب الأقسام

## الهدف

تمكين مستخدم الموارد البشرية من عرض سجلات الحضور اليومي لأقسام محددة عبر فلتر متعدد الاختيار، مع اختيار أقسام الفيلم والطباعة والتقطيع والمستودع افتراضياً.

## التصميم

- تبقى الصفحة داخل تبويب «الحضور اليومي» وتحتفظ بحقل التاريخ الحالي.
- تُحمّل قائمة الأقسام من `GET /api/sections`، وتُعرض التسمية العربية أو الإنجليزية حسب اللغة.
- تُحدد الاختيارات الافتراضية بمطابقة الأسماء بعد `trim` وبمطابقة غير حساسة لحالة الأحرف في الإنجليزية:
  - الفيلم: `الإنتاج - فيلم` أو `Production-Extruder`.
  - الطباعة: `الإنتاج - طباعة` أو `Production-Printing`.
  - التقطيع: `الإنتاج - قطع` أو `Production-Cutting`.
  - المستودع: `المستودع` أو `Warehouse`.
  لا تُستخدم معرّفات ثابتة. عند وجود أكثر من تطابق لنفس المجموعة، يُختار المعرّف الأصغر ترتيباً، وعند عدم وجود تطابق تُترك تلك المجموعة غير محددة.
- يرسل العميل مع طلب الحضور اليومي `sectionIds` بصيغة CSV في query string، مثل
  `sectionIds=SEC03,SEC04`. يقبل الخادم أيضاً مصفوفة query مكررة للتوافق. القيمة المفردة الموجودة والفارغة تماماً `sectionIds=` هي التمثيل الصريح الوحيد لقائمة فارغة، ويجب أن يستخدمها العميل بعد «إلغاء الكل». بعد معالجة هذه الحالة أولاً، يتحقق الخادم من أن كل قيمة غير فارغة على صورة `SEC` متبوعة بأرقام؛ أي قيمة فارغة داخل CSV غير فارغ، أو داخل مصفوفة query مكررة (بما في ذلك خلطها مع قيمة صحيحة)، أو أي قيمة أخرى غير صحيحة تعيد `400`.
- يحوّل الخادم المعرّفات النصية الآمنة `SEC<number>` إلى أرقام لمطابقة نوع `users.section_id`، ويتجاهل المعرّفات الصحيحة شكلياً التي لا تطابق أي قسم/مستخدم. يضيف شرط `users.section_id IN (...)` إلى قائمة الموظفين النشطين المشمولين في الحضور.
- عند إرسال قائمة فارغة، يعيد الخادم قائمة فارغة؛ لا تظهر أي صفوف حتى يختار المستخدم قسماً.
- غياب `sectionIds` عن الطلب يحافظ على سلوك المسار السابق ويعرض جميع الموظفين المؤهلين؛ أما وجوده بقائمة فارغة فيعني صراحةً عرض لا شيء.
- لا يبدأ طلب الحضور قبل اكتمال تحميل الأقسام وتحديد الاختيارات الافتراضية. إذا فشل تحميل الأقسام تُعتبر الحالة محسومة بقائمة فارغة، ولا يعود الطلب إلى نتائج غير مفلترة.
- لا تتغير صلاحيات التعديل أو الإشعار، ولا تتأثر وظيفة تغيير التاريخ.
- تبقى الاختيارات في حالة مستقلة عن التاريخ وتُحفظ عند تغييره.
- يتضمن عنصر التحكم خيار تحديد الكل وإلغاء الكل، ويعرض ملخصاً بعدد الأقسام المحددة.

## التحقق

- الاختيارات الافتراضية تعرض أقسام الفيلم والطباعة والتقطيع والمستودع فقط.
- اختيار قسمين يعرض موظفي القسمين فقط.
- إلغاء جميع الاختيارات يعرض الجدول الفارغ.
- تغيير التاريخ مع وجود الفلتر يحافظ على الأقسام المختارة.
- غياب `sectionIds` عن الاستدعاء البرمجي القديم يبقى غير مفلتر.
- فحص TypeScript والبناء وتشغيل التطبيق.
