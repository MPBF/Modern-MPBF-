# شجرة صفحات نظام MPBF

> **الغرض:** مرجع مبسط لبنية صفحات التطبيق ومساراتها وتبويباتها الداخلية.  
> **مصدر التوثيق:** المسارات وتعريفات التنقل والصلاحيات الموجودة في الكود.  
> **تاريخ آخر مراجعة:** 7 سبتمبر 2026.  
> **مهم:** التبويب الداخلي ليس صفحة مستقلة ما لم يُذكر له مسار URL مستقل.

## مفتاح القراءة

| الرمز | المعنى |
|---|---|
| 🌐 | صفحة عامة لا تتطلب تسجيل الدخول |
| 🔐 | صفحة تتطلب تسجيل الدخول |
| 🛡️ | صفحة مقيدة بصلاحيات |
| 🖥️ | صفحة عرض خاصة أو بملء الشاشة |
| ↪️ | مسار قديم يحوّل إلى مسار أحدث |
| 🪟 | نافذة أو معالج مضمّن، وليس مساراً مستقلاً |

تتعامل مصفوفات الصلاحيات المذكورة في هذا الملف كبدائل؛ يكفي عادة امتلاك إحدى الصلاحيات. المستخدم الذي يملك صلاحية `admin` يتجاوز قيود المسارات.

## 2. الصفحات العامة والمصادقة

### 2.1 تسجيل الدخول 🌐

- **المسار:** `/login`
- **الوصف:** تسجيل دخول المستخدم إلى النظام.
- **السلوك:** إذا كان المستخدم مسجلاً بالفعل، يُوجّه إلى الصفحة الرئيسية.

### 2.2 تغيير كلمة المرور 🔐

- **المسار:** `/change-password`
- **الوصف:** تغيير كلمة المرور، ويُستخدم أيضاً عند إلزام المستخدم بتغييرها في أول دخول.
- **السلوك:** المستخدم غير المسجل يُوجّه إلى صفحة الدخول.

### 2.3 عرض سعر وتصميم الأكياس العام 🌐

- **المسار:** `/mpbf`
- **الوصف:** واجهة عامة مناسبة للهاتف لإعداد مواصفات كيس أو عرض سعر دون دخول إلى النظام.

### 2.4 عرض الطلب العام 🌐

- **المسار:** `/view/order/:token`
- **الوصف:** عرض بيانات طلب باستخدام رابط أو رمز QR آمن.
- **المعامل:** `:token` رمز مشاركة الطلب.

### 2.5 إعداد الشركة

- **المسار:** `/setup`
- **الوصف:** إعداد بيانات الشركة الأساسية عند تجهيز النظام.
- **ملاحظة:** الصفحة مركبة خارج غلاف الحماية المعتاد، ولا تظهر معها القائمة الجانبية.

### قواعد المصادقة العامة

- الصفحات المحمية توجّه المستخدم غير المسجل إلى `/login`.
- عند غياب الصلاحية تظهر صفحة «غير مصرح» مع خيارات العودة أو تسجيل الخروج.
- إذا كان `must_change_password` مفعلاً، يُوجّه المستخدم إلى `/change-password` قبل متابعة استخدام الصفحات المحمية.

### 4.2 طلباتي 🔐 🛡️

- **المسار:** `/my-orders`
- **الوصف:** عرض الطلبات المرتبطة بالمستخدم الحالي، خصوصاً مستخدمي المبيعات.

### 4.3 العملاء 🔐 🛡️

- **الصلاحيات:** إحدى صلاحيات عرض/إدارة الطلبات أو العملاء أو التعريفات.

### 4.4 إدارة العملاء 🔐 🛡️

- **المسار:** `/customer-management`

- **الصلاحيات:** `manage_customers` أو `manage_definitions`.

## 5. الإنتاج

### 5.1 لوحة الإنتاج الموحدة 🔐 🛡️

- **المسار:** `/production-dashboard`
- **الوصف:** لوحة تشغيل موحدة لمراحل الفيلم والطباعة والقص وإنتاج اليوم.
- **الصلاحيات:** إحدى صلاحيات عرض أو إدارة الإنتاج، أو صلاحية لوحة المرحلة التشغيلية المناسبة، أو `view_today_production`.
- **التبويبات، وتظهر حسب صلاحيات المستخدم:**
  - **الفيلم — `film`:** تشغيل ومتابعة مرحلة إنتاج الفيلم.
  - **الطباعة — `printing`:** تشغيل ومتابعة مرحلة الطباعة.
  - **القص — `cutting`:** تشغيل ومتابعة مرحلة القص.
  - **إنتاج اليوم — `today`:** مراجعة الأعمال والإنتاج المنفذ خلال اليوم.
  - **الرولات — `rolls`:** إدارة الرولات، ويظهر للمستخدم المخول بإدارتها.
- **ملاحظة:** حلت محل صفحات مشغلي الفيلم والطباعة والقص القديمة.

### 5.2 طوابير الإنتاج 🔐 🛡️

- **المسار:** `/production-queues`
- **الوصف:** ترتيب الأعمال قيد الانتظار ومراقبة توزيعها على مراحل الإنتاج.
- **الصلاحيات:** عرض/إدارة الإنتاج أو عرض/إدارة الطلبات.
- **التبويبات:**
  - **الفيلم — `film`**
  - **الطباعة — `printing`**
  - **القص — `cutting`**

### 5.3 مراقبة الإنتاج 🔐 🛡️

- **المسار:** `/production-monitoring`
- **الوصف:** متابعة حالة الطلبات وتقدمها بين مراحل التصنيع.
- **الصلاحيات:** `view_production_monitoring` أو `view_production`.

### 5.4 خلط المواد 🔐 🛡️

- **المسار:** `/material-mixing`
- **الوصف:** إدارة وتشغيل وصفات وعمليات خلط المواد المستخدمة في الإنتاج.
- **الصلاحيات:** `view_mixing` أو `manage_mixing` أو `view_production`.

### 5.5 تتبع التشغيلة 🔐 🛡️

- **المسار:** `/batch/:batchNumber`
- **الوصف:** البحث عن تشغيلة وعرض بيانات التتبع المرتبطة بها، ويُستخدم مع رموز QR.
- **المعامل:** `:batchNumber` رقم التشغيلة.
- **الصلاحيات:** إحدى صلاحيات الإنتاج أو الطلبات.

### 5.6 مكوّن الأكياس 🔐 🛡️

- **المسار:** `/bag-configurator`
- **الوصف:** معالج متدرج لتحديد مواصفات الكيس ومعاينته وحساب بياناته.
- **الصلاحيات:** `view_bag_configurator` أو `manage_orders`.
- **خطوات المعالج:**
  1. نوع الكيس.
  2. المادة.
  3. الأبعاد.
  4. المقبض.
  5. اللون.
  6. الطباعة وتصميمها وحالتها.
  7. النتائج.
  8. المعاينة.

## 6. الجودة

### 6.1 الجودة 🔐 🛡️

- **المسار:** `/quality`
- **الوصف:** تسجيل قضايا الجودة وفحصها وتحليلها ومتابعة الإجراءات الناتجة عنها.
- **الصلاحيات:** `view_quality` أو `manage_quality`.
- **التبويبات الرئيسية:**
  - **القضايا — `issues`:** قائمة مشكلات وقضايا الجودة.
  - **الفحوصات:** مراجعة عمليات الفحص والتدقيق.
  - **لوحة الجودة — `dashboard`:** مؤشرات وإحصاءات الجودة.

### 6.2 تفاصيل قضية الجودة

تظهر داخل صفحة الجودة وليست مساراً مستقلاً:

- **التفاصيل — `details`:** وصف القضية وبياناتها الأساسية.
- **المسؤولون — `responsibles`:** الأشخاص أو الأقسام المعنية.
- **الإجراءات — `actions`:** الإجراءات التصحيحية والمتابعة.
- **الوقائية — `preventive`:** إجراءات منع تكرار المشكلة.
- **الخسائر — `losses`:** الخسائر والكميات والتكاليف المرتبطة.
- **العميل — `customer`:** بيانات العميل المتعلقة بالقضية.

## 8. الصيانة

### 8.1 الصيانة 🔐 🛡️

- **المسار:** `/maintenance`
- **الوصف:** مركز إدارة طلبات الصيانة والإجراءات والقطع والصيانة الدورية والوقائية.
- **الصلاحيات العامة:** `view_maintenance` أو `manage_maintenance`.

#### أ. الصيانة التصحيحية — `corrective`

- **طلبات الصيانة — `requests`:** استقبال ومتابعة بلاغات الأعطال.
- **الإجراءات — `actions`:** تنفيذ وتوثيق أعمال الصيانة.
- **التقارير — `reports`:** تحليل أعمال وأداء الصيانة.
- **الإهمال — `negligence`:** توثيق حالات الإهمال المرتبطة بالأعطال أو الصيانة.

#### ب. مخزون الصيانة — `inventory`

- **قطع الغيار — `spare-parts`:** إدارة قطع الغيار وحركاتها.
- **المواد الاستهلاكية — `consumable-parts`:** إدارة المواد التي تُستهلك أثناء الصيانة.
- **كتالوج المكونات — `component-catalog`:** تعريف مكونات الماكينات والمعدات.

#### ج. الصيانة الوقائية — `preventive`

- **الإجراءات الوقائية — `preventive-actions`:** الإجراءات المخططة لمنع الأعطال.

#### د. الصيانة الدورية — `periodic`

- **جدول الصيانة الدورية — `periodic-maintenance`:** إعداد الدورات وقوائم الفحص ومتابعة الاستحقاق والتنفيذ.

#### هـ. المهندس الذكي — `smart-engineer`

- **مساعد مهندس الصيانة:** أداة مساعدة لتحليل الأعطال ودعم أعمال الصيانة.

#### واجهات مضمّنة مهمة 🪟

- ملف صيانة الماكينة.
- نافذة إنشاء أو تعديل طلب صيانة.
- تفاصيل الإجراء وسجلات القطع المستخدمة.

## 9. الموارد البشرية والحضور

### 9.1 الموارد البشرية 🔐 🛡️

- **المسار:** `/hr`
- **الوصف:** مركز ملفات الموظفين والحضور والورديات والتقارير والمخالفات والطلبات.
- **الصلاحيات العامة:** إحدى صلاحيات عرض أو إدارة أو تعديل أو حذف بيانات الموارد البشرية.
- **التبويبات:**
  - **دليل الموظفين — `directory`:** قائمة الموظفين والوصول إلى ملفاتهم.
  - **الحضور اليومي — `daily`:** مراقبة سجلات حضور اليوم وتصحيحها حسب الصلاحية.
  - **جدول الورديات — `roster`:** إنشاء قوالب الورديات وتوزيعها شهرياً على الموظفين.
  - **تقرير الحضور — `report`:** مراجعة وتحليل الحضور لفترة محددة.
  - **مخالفات العمل — `violations`:** إدارة مخالفات الموظفين.
  - **الطلبات — `requests`:** إدارة طلبات الموارد البشرية، ويظهر للمستخدم المخول فقط.

### 9.2 ملف الموظف المضمّن 🪟

- **الوصول:** اختيار موظف من دليل الموظفين داخل `/hr`.
- **الوصف:** ملف تفصيلي للموظف؛ لا يملك URL مستقلاً.
- **الأقسام المتخصصة:**
  - البيانات الأساسية والوظيفية.
  - المخالفات.
  - المكافآت.
  - التدريب.
  - السمات والتقييم.
  - الأجور وحساب الأجر الشهري.
- **صلاحيات العمليات:** توجد صلاحيات مستقلة للإضافة والتعديل والحذف، وتوجد صلاحيات خاصة بالتدريب.

## 22. مصادر التحقق في الكود

أهم الملفات المرجعية المستخدمة للحفاظ على هذا المستند:

- `client/src/App.tsx` — تعريف مسارات التطبيق والتحويلات.
- `client/src/config/navigationConfig.ts` — عناصر القائمة الجانبية وأسماؤها.

- `shared/permissions.ts` — صلاحيات المسارات وأقسام الإعدادات.
- `client/src/utils/roleUtils.ts` — طريقة التحقق من الوصول.
- `client/src/pages/` — الصفحات وتبويباتها.
- `client/src/components/hr/` — تفاصيل الموارد البشرية وملف الموظف.
- `client/src/components/maintenance/` — مجموعات وتبويبات الصيانة.

عند إضافة صفحة أو تغيير تبويب أو مسار، يجب تحديث هذا الملف مع تعريفات المسار والتنقل والصلاحيات في التغيير نفسه.
